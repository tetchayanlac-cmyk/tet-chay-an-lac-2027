Đơn vị tham gia

Hướng dẫn nhập hàng loạt
  1. Bấm Tải file Excel mẫu, điền mỗi đơn vị một dòng. Sản phẩm tiêu biểu cách nhau bằng dấu ;
  2. Cột Tên file logo ghi đúng tên file ảnh (ví dụ hop-tac-xa-an-lac.png). Để trống thì hệ thống tự ghép theo tên đơn vị.
  3. Bấm Nhập từ Excel/CSV. Đơn vị trùng tên sẽ được cập nhật, đơn vị mới được thêm vào.
  4. Bấm Tải logo hàng loạt, chọn tất cả file logo cùng lúc (Ctrl+A trong thư mục). Logo được tự động thu nhỏ.
  5. Kiểm tra lại rồi bấm Lưu & xuất bản. Website cập nhật ngay.
